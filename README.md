# Hotel Booking System (Лабораторная работа №15)

Консольное приложение на Java для управления бронированием гостиничных номеров (Вариант 2).

## Назначение
Автоматизация процессов гостиничного учета: хранение номерного фонда, поиск свободных номеров на заданные даты, расчет стоимости проживания, регистрация и отмена бронирований, предотвращение повторной брони на пересекающийся период, а также файловое сохранение и восстановление данных.

## Возможности
- Учет номеров различных категорий: стандартные (`StandardRoom`) и повышенной комфортности (`SuiteRoom`).
- Расчет стоимости проживания с учетом категории номера и скидки.
- Поиск свободных номеров на заданный диапазон дат.
- Регистрация бронирования с проверкой занятости номера.
- Генерация проверяемого исключения `RoomAlreadyBookedException` при попытке забронировать занятый номер на пересекающийся период.
- Отмена активных бронирований.
- Сохранение и загрузка данных из текстового файла (`FileStorage`) с использованием `try-with-resources`.
- Интерактивное консольное меню и встроенный автоматический тест-демо сценарий.

## Архитектура
Проект разделен на пакеты по принципам SOLID:
- `model` — сущности предметной области (`Room`, `StandardRoom`, `SuiteRoom`, `Booking`).
- `exception` — исключение `RoomAlreadyBookedException`.
- `service` — интерфейс `IBookingService` и реализация бизнес-логики `HotelService`.
- `storage` — файловый ввод-вывод (`FileStorage`).
- `util` — обобщенный класс-контейнер `Container<T>`.
- `app` — точка входа `Main`.

## Инструкция по сборке и запуску (полный цикл)

### 1. Клонирование репозитория
```bash
git clone https://github.com/D1verlin/OKP-15.git
```

### 2. Переход в каталог проекта
```bash
cd OKP-15
```

### 3. Компиляция проекта
```bash
javac -encoding UTF-8 -d bin src/model/*.java src/exception/*.java src/util/*.java src/storage/*.java src/service/*.java src/app/*.java
```

### 4. Запуск приложения
```bash
java -cp bin app.Main
```
